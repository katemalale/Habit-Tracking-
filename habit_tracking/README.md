# Python Habit Tracking App

## 1. Project Overview

The Python Habit Tracking App is a command-line application designed to help users record, manage and analyse their daily and weekly habits. It stores habit information and completion records in a database and provides basic analytics to help users monitor their progress.

## 2. Features

- Create and manage habits.
- Track daily and weekly habits.
- Record habit completions.
- View habit progress and completion history.
- Analyse habit performance.
- Use sample data to demonstrate the application's functionality.

## 3. Technologies Used

- Python
- SQLite or the database configured in `database.py`
- Python standard libraries and any additional dependencies used by the project

## 4. Project Structure

- `main.py` — Application entry point.
- `cli.py` — Command-line interface.
- `database.py` — Database operations.
- `habit_manager.py` — Habit management functionality.
- `analytics.py` — Habit statistics and analysis.
- `sample_data.py` — Sample data for testing and demonstration.

## 5. Installation

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Install any dependencies listed in `requirements.txt`, if provided.
5. Run the application using the appropriate command below.

## 6. Running the Application

Run the application from the project directory:

```bash
python main.py
```

If your environment uses `python3`, run:

```bash
python3 main.py
```

## 7. Testing and Sample Data

The project includes sample data to demonstrate habit tracking and analytics. Follow the application's available commands to explore the features and verify that habit records and completion history are handled correctly.

## 8. Limitations and Future Improvements

Potential future improvements include adding a graphical user interface, user accounts, reminders, and more detailed progress visualisations.
